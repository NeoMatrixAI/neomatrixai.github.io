/how-it-works

From your Python file to a live book.

Write each strategy once, the same code for backtest and live. The platform validates it, nets it together with every other strategy in the account, executes the orders, and records everything around the clock.

Build · same code, backtest to live

1. Compose

Build an alpha, group alphas into a portfolio, package portfolios into a fund, all in the same browser IDE.

2. Backtest

Run it against real historical data. Results persist and export, so you can compare runs over time.

3. Go Live

Publish the exact same code. It's netted together with every other strategy in the account and traded live.

Protect · built to be trusted with real capital

Guardrails, always on

Allocations never exceed 100%, a failed strategy holds its last position instead of being force‑sold, and a genuinely empty signal never auto‑liquidates the account.

Nothing hidden

Every minute, the sum of every virtual scorecard is checked against the real account. Any gap (fees, funding, timing) is shown, never quietly absorbed.

One code, backtest to live

The exact same alpha/portfolio/fund code runs in backtest and in production. No rewrites, no drift between what you tested and what trades.

Every session, on the record

The exact strategy code, config and fills are snapshotted, so you can replay or audit any past trade, anytime.

Self‑healing by design

If a node or job dies mid‑session, the platform detects it and recovers your positions automatically. No babysitting.

Hot‑swap, no downtime

Update a strategy or config while it's live. It takes effect on the next cycle, with no restart.

All of it runs on Kubernetes: self‑healing, snapshotted for audit. You bring the strategy; we keep it running.
